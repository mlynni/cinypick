# Інтерактивна стрічка вибору років у Розширеному пошуку

Виправлення блокування подвійного повзунка років (коли обидва маркери опиняються в одній точці, наприклад `2026 — 2026`) та додавання прямого керування кліком і подвійним кліком по стрічці.

### User Review & Critical Decisions

> [!IMPORTANT]
> Причина помилки та нова поведінка стрічки років:

- **Чому виникало блокування**: Раніше використовувалися два накладені системні `<input type="range">`, де верхній повзунок (`yearTo`) перекривав нижній (`yearFrom`) і мав обмеження `Math.max(val, yearFrom)`. Коли обидва маркери ставали на `2026`, верхній маркер не дозволяв тягнути вліво, а нижній був перекритий під ним.
- **Одинарний клік та перетягування по стрічці**: Натискання в будь-якому місці стрічки одразу ставить туди найближчий маркер. Якщо обидва маркери стоять в одній точці (наприклад, `2026 — 2026`), клік або рух ліворуч автоматично рухає ліву межу (`yearFrom`), а праворуч — праву межу (`yearTo`).
- **Подвійний клік по стрічці**: Подвійне натискання в будь-якій точці стрічки встановлює обидва маркери на цей конкретний рік (`yearFrom = yearTo = обраний рік`), щоб шукати фільми лише за цей рік.

---

### 1. Overview & Core Concept

- **Що змінюється**: Замість двох конфліктуючих накладених `<input type="range">` реалізується єдина чутлива стрічка з власним розрахунком координати курсора (`Pointer Events`).
- **Ключова перевага**: Повзунки більше ніколи не застрягають в одній точці, миттєво реагують на клік у будь-якому місці шкали та підтримують швидкий вибір одного року подвійним кліком.

---

### 2. User Experience & Visual Design

- **Взаємодія зі стрічкою**:
  1. **Клік по стрічці**: Визначається рік у точці кліку, і найближчий повзунок миттєво переміщується в цю точку (з можливістю одразу вести мишу далі, не відпускаючи кнопку).
  2. **Вихід зі стану одного року (`2026 — 2026`)**: Якщо обидва повзунки зведені в один рік, будь-яке перетягування або клік ліворуч розширює діапазон вліво, а праворуч — вправо.
  3. **Подвійний клік (`Double Click`)**: Обидва повзунки стають у точку подвійного кліку, обираючи рівно один рік.

---

### 3. Technical Architecture & Data Strategy *(Technical Reference)*

```
┌─────────────────────────────────────────────────────────────────────────┐
│                Інтерактивна стрічка років (Pointer Track)               │
│  • Обчислення року з координати X:                                      │
│    ratio = clamp((clientX - rect.left) / rect.width, 0, 1)              │
│    targetYear = round(MIN_YEAR + ratio * (CURRENT_YEAR - MIN_YEAR))     │
├───────────────────────────────────┬─────────────────────────────────────┤
│   Одинарний клік / Перетягування  │        Подвійний клік (DblClick)    │
│ • Якщо yearFrom === yearTo:       │ • Встановлює:                       │
│   target < year -> рухає yearFrom │   yearFrom = targetYear             │
│   target > year -> рухає yearTo   │   yearTo   = targetYear             │
│ • Інакше рухає ближчий маркер     │                                     │
└───────────────────────────────────┴─────────────────────────────────────┘
```
